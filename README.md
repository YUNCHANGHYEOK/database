# 주식 백테스팅 플랫폼

키움증권 API로 주가 데이터를 가져와서 삼성전자(005930)의 간단한 백테스팅을 돌려보는 프로젝트입니다. 
가격 기반이랑 RSI 기반으로 매매 전략을 테스트해볼 수 있고, 결과를 비교할 수 있게 만들었습니다.

## 구조

```
database/
├── back/
│   ├── app.js              # Node.js HTTP 서버
│   ├── db/                 # MySQL 연결 설정
│   └── package.json
│
├── front/
│   ├── index.html          # 메인 페이지
│   ├── script.js           # 백테스팅 로직
│   └── style.css
│
└── API_pull/
    └── fetch_rsi.py        # 키움 API로 데이터 수집
```

## 기능

### 데이터 수집
- 키움증권 모의투자 API 사용
- 일봉 데이터랑 RSI 같이 계산해서 MySQL에 저장
- 날짜 범위 지정해서 원하는 기간만 가져올 수 있음

### 백테스팅
두 가지 방식으로 테스트 가능:
- 가격 기반: 특정 가격에서 사고팔기 (예: 50000원 매수, 55000원 매도)
- RSI 기반: RSI 값으로 매매 타이밍 잡기 (예: RSI 40 이하 매수, 70 이상 매도)

### 결과 비교
- 최근 백테스팅 결과 10개 저장됨
- 가격 vs RSI 전략 성과를 차트로 비교
- 거래 내역 CSV 다운로드

### 차트
- 실제 주가 위에 매수/매도 지점 표시
- 마우스 올리면 날짜랑 가격 나옴
- 평균 RSI 표시

## 실행 방법

### 데이터 수집
웹에서 "데이터 수집 시작" 버튼 누르면 됨
- 시작일/종료일 입력 (예: 2024-01-01, 2024-05-31)
- Python으로 키움 API 호출해서 CSV 생성
- Node.js가 CSV 읽어서 DB에 저장
